# 资金流向实现详情

## 数据源层级

### 1. 板块资金流向（主力/散户）
- **接口**: 新浪 MoneyFlow.ssl_bkzj_bk (fenlei=2)
- **返回字段**: name, netamount(净流入), inamount(流入), outamount(流出)
- **单位**: 元，需除以100000000转亿元
- **频率**: 每天15:30入库

### 2. 北向资金（沪股通/深股通）
- **接口**: 东财数据中心 RPT_MUTUAL_DEAL_HISTORY
- **关键参数**: pageSize>=20（006在第4条以后）
- **MUTUAL_TYPE**: 001=沪股通, 003=深股通, 006=北向合计
- **单位**: 万元，需除以10000转亿元

### 3. 融资融券（近似）
- **当前方案**: 用板块资金流向近似
- **展示时标注**: "板块资金情绪（主力资金流向近似）"

### 4. ETF申赎（近似）
- **当前方案**: 用ETF涨跌幅近似申赎方向
- **展示时标注**: "ETF资金动向（涨跌幅近似申赎方向）"

### 5. 全市场资金类型（待实现）
- **数据源**: 机构/主力/大户/散户
- **参考**: 用户分享的抖音视频数据
- **状态**: 未入库，仅参考

## 坑点记录

1. **北向资金pageSize必须>=20**: MUTUAL_TYPE=006不在前3条
2. **新浪API返回资金流向非涨跌幅**: 用净流入排名替代涨跌幅排名
3. **融资融券/ETF申赎为近似数据**: 真实接口暂不可用
4. **全市场资金类型**: 用户关注但未入库，后续可考虑
5. **数据库连接冲突**: Pipeline主流程和资金流向入库必须用独立连接
6. **散户数据简化**: retail_netflow = -netamount
