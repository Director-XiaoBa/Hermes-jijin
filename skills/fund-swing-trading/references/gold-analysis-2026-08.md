## 四大归因（按权重）
1. **地缘避险溢价（最直接引爆点）**：美伊战事→霍尔木兹封锁→全球避险资金涌入。协议"接近达成"≠尘埃落定，局势随时反复（08-06空袭），避险溢价持续。
2. **央行购金潮（长线主线）**：去美元化/储备多元化，2026年金价疯涨70%的底层逻辑。东财原话标题："4000美元筑底成功？地缘风险叠加央行购金潮 年内金价或重回上行通道"。
3. **油价跌→通胀预期降→加息押注逆转**：油价暴跌6%→"美联储9月可能不加息"押注升温→实际利率预期下行→利好黄金。⚠️ 反向声音也在（08-06 库克/卡什卡利仍喊加息）——宏观拉锯，非单边利多。
4. **技术面：4000美元筑底成功**：回调-18%后在4000企稳，8月放量突破4200。

## 美联储鹰派 vs 黄金（08-28 实案：沃什杰克逊霍尔放鹰，黄金-3.4%）

### 核心传导链
```
美联储鹰派 → 加息预期升温 → 美元走强 + 实际利率上升 → 黄金承压
```

### 为什么黄金跌（不是"避险失灵"）

**① 加息预期 → 实际利率上升 → 黄金最大利空**
- 黄金本身不生息
- 市场预期美联储加息 → 名义利率上升
- 如果通胀预期不变 → 实际利率（名义-通胀）上升
- 持有黄金的机会成本变高（买债券能拿更多利息，干嘛持有没有利息的黄金？）
- 资金从黄金流出 → 金价下跌

**② 加息预期 → 美元走强 → 黄金承压**
- 加息预期让美元资产更有吸引力（利息更高）
- 美元指数上涨
- 黄金以美元计价，美元涨 → 黄金对非美买家变贵 → 需求下降 → 金价跌

**③ 这次为什么跌这么狠（-3.4%）**
- 市场之前预期沃什会偏鸽（毕竟之前有降息预期）
- 结果他直接放鹰，预期差很大
- 两年期美债收益率 +10bp（债券价格跌，收益率涨）
- 黄金-3.4%（反应最剧烈）

### 为什么避险没救黄金？

| 避险事件 | 黄金表现 | 原因 |
|:--|:--|:--|
| 地缘冲突（战争） | ✅ 涨 | 资金逃离风险资产 |
| 经济衰退恐慌 | ✅ 涨 | 预期降息 |
| **美联储加息** | ❌ 路 | **加息=美元涨+利率涨=黄金双杀** |

沃什放鹰本质上不是"风险事件"，是**货币政策收紧信号**。这种情况下：
- 避险资金不是"逃向黄金"，是"逃向美元"
- 美元和黄金是竞争关系，美元强则黄金弱

### 对000217持仓的影响
- 金价跌3.4% → 000217周一大概率低开2-3%
- 止损-10%（2700元成本），目前应该还在安全区间
- 定投角度：金价跌反而是好事——同样3000元能买更多份额
- 但短期别急着加仓，等金价企稳再看

### 黄金大涨归因 vs 黄金大跌归因（对比）

| 场景 | 核心驱动 | 黄金方向 | 关键指标 |
|:--|:--|:--|:--|
| 地缘避险（美伊/霍尔木兹） | 避险资金涌入 | ✅ 涨 | 油价、地缘新闻 |
| 央行购金潮 | 去美元化/储备多元化 | ✅ 涨 | 央行持仓数据 |
| 油价跌→通胀预期降→加息押注逆转 | 实际利率预期下行 | ✅ 涨 | 油价、CPI |
| **美联储鹰派（加息预期）** | **实际利率上升+美元走强** | **❌ 路** | **美债收益率、美元指数** |
| **美联储鸽派（降息预期）** | **实际利率下行+美元走弱** | **✅ 涨** | **美债收益率、美元指数** |

**核心区别：地缘/央行/油价是"外部事件驱动"，美联储是"货币政策驱动"。前者避险逻辑主导，后者利率逻辑主导。**
