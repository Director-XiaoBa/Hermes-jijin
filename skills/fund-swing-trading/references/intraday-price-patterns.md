# 盘中形态速查（低开高走/高开低走/低开低走/高开高走/冲高回落/探底回升）

用户08-05确认理解这套框架。教学顺序（已验证有效）：先讲3个基础词 → 再拆6种形态 → 最后给"终极记忆法"+"操作三句"。用户曾表示"全部都不懂"，所以要从零讲，别默认他会。

## 三个基础词（先讲这个）
- **昨收**：昨天收盘价（昨天结束的位置）
- **今开**：今天9:30开盘价（今天醒来站的位置）
- **收盘**：15:00最终价（今天结束的位置）
- 高开/低开/平开 = 今开 vs 昨收 的对比

## 六种形态
| 形态 | 一句话记忆 | 谁在跑/在接 | 信号 |
|---|---|---|---|
| 低开高走 | 跌着开，涨着收 | 有人接，恐慌被买走 | 🟢 可能见底 |
| 高开低走 | 涨着开，跌着收 | 有人跑，趁高派发 | 🔴 资金撤离 |
| 低开低走 | 跌着开，继续跌 | 没人接，恐慌延续 | 🔴🔴 别接飞刀 |
| 高开高走 | 涨着开，继续涨 | 都在买，最强 | 💪 持仓考虑卖，空仓别追 |
| 冲高回落 | 先冲到顶，再跳水 | 上方抛压重 | 🔴 卖点 |
| 探底回升 | 先砸到底，再拉回 | 下方承接 | 🟢 买点 |

## 终极记忆法
1. **只看"收尾"**：收盘比开盘高 = 偏强（高走/回升）；收盘比开盘低 = 偏弱（低走/回落）
2. 探底回升 = 低开高走的加强版（砸得更深拉得更猛）；冲高回落 = 高开低走的加强版（冲得更高跌得更狠）
3. **操作三句**：低开高走/探底回升 → 结合跌透门槛可进场；高开低走/冲高回落 → 该卖；低开低走 → 什么都不做等

## 与v1.1策略的接口（关键）
- 进场"追加确认" = 当天不再创新低 / 低开高走 / 板块逆势翻红 —— 就是盘中形态判断
- 卖出锚"冲高回落" = 盘中冲高+X%尾盘只剩+Y%（资金在跑）
- **场外基金只能15:00前下单按当天净值成交** → 决策集中在14:00-15:00，14:30尾盘确认（14:40 cron任务落地）

## 08-05实盘案例（教学用活例）
光模块"美国禁令"传闻日：中际旭创低开-13.9% → 拉回-7.6%（从低点回升+7.3%，探底回升）；新易盛-10.7%→-5.7%；天孚-9.0%→-0.8%。同日寒武纪高开高走+5.5%。结论：恐慌被买盘接走 = 教科书级探底回升，说明消息是传闻（旭创辟谣FCC未出文件），资金在低位接货。
