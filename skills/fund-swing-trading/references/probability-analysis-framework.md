# 基金概率分析框架

> 08-25 实战产出：用户问"概率是多少"时的标准分析流程。用历史回测数据给出具体百分比。

## 触发条件
- 用户问"概率是多少" / "胜率多大" / "有多大把握"
- 用户需要量化决策依据

## 四步概率分析法

### Step 1：当前位置定位
从 pingzhongdata 拉近90日数据：
- 距历史最高回撤 = (最新/90日最高-1)*100
- 距30日低点反弹 = (最新/30日最低-1)*100

关键锚点（025422实测）：
- 回撤>25% → 20日内100%反弹，平均+9.7%（27次样本）
- 回撤>40% → 20日内平均反弹+18%

### Step 2：大涨大跌后统计
全量净值数据计算：
- 大涨(>=+5%)后3日仍涨概率 + 平均收益
- 大跌(<=-5%)后3日反弹概率 + 平均收益
- 连涨N天后次日概率分布

025422实测：大涨后3日64%仍涨，大跌后3日77%反弹+5.0%

### Step 3：分情景概率矩阵
按催化剂设3情景（超预期/符合/不及预期），各赋概率和预估收益，算期望值。
期望值为正=值得买。

### Step 4：风险端量化
最大历史跌幅=止损参考，波动率=仓位建议（高波动=轻仓）

## 输出格式
期望值计算 + 关键胜率表（2周/1月盈利概率+平均收益）

## 已验证案例
- 025422（08-25）：2周盈利概率65~70%，期望+1.5~2.5%
