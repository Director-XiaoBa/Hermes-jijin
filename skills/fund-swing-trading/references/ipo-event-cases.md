# IPO事件案例库（长鑫科技 / 宇树科技）

两个大IPO事件的时间线、板块影响实测数据，用于对照"上市吸血→暴跌→进场"剧本。

## 长鑫科技（688825，存储芯片）—— 已验证案例 ✅

| 时间 | 事件 | 板块反应（科创50联接011613） |
|:---|:---|:---|
| 07-24 | 官宣07-27科创板上市+进科创50 | 上市前情绪高点 |
| 07-27 | 上市首日：开49.5，最低38.11（振幅44%） | 当天1.4161（小涨） |
| 07-28~30 | 长鑫震荡（47→52.95→52.87） | **科创50连续暴跌：1.4161→1.2535（-11.5%）** |
| 07-31 | 长鑫+8.95%（57.6元） | 芯片反弹+7%（韩股驱动，与长鑫无关） |

**关键数据**：
- **拟募资295亿（注册时），实际募资约579亿（超额配售前），最高666亿（超额配售全额）**——A股年内最大IPO、科创板史上第二大（仅次于中芯532亿）。信源：风闻/同花顺/新浪
- 发行价8.66元/股，中一签（500股）成本4330元，开盘49.5元 → **中一签赚约2.04万（+471%）**
- 上市后板块累计跌幅 **-10.4%**（触发模式A的-10%线）
- 教训：**IPO预期阶段=机会，落地阶段=风险**。长鑫上市=板块情绪顶点，之后回落
- **低点窗口实测**：上市日(07-27)→第3个交易日后见底(07-30)→次日(07-31)反弹。从官宣到低点4个交易日

- 申购日当天（T）机器人重仓股**全线开跌**：大族激光-4.80%、绿的谐波-4.16%、双环传动-2.11%、拓普-1.81%、三花-1.41%（14:08实时）→ **"申购日=情绪高潮=短期高点兑现"在宇树上兑现**，不是打新成功后板块才跌，是申购日当天就开始派发
- 018345 官方净值 1.2277（08-07，申购日前最后一值），近3日仍 +3.9% 反弹，**未触发跌透门槛 → 申购日不进场**
- 进场线现口径 **1.10~1.12**（08-04 起用户/策略统一为 1.10~1.12，早前预演的 1.05~1.07 已废弃）
- 操作结论：申购日=空仓等，下一评估点=上市后第3~5交易日低点窗口 + 8/19-23 机器人大会前若未跌透则继续等

## 打新资格（普通散户现实）

科创板打新硬条件：前20交易日日均资产≥50万 + 2年交易经验 + 沪市市值挂钩额度。
用户只买场外基金 → 通常无打新资格 → 只能吃板块情绪波动（暴跌进场/暴涨卖出），赚不到打新收益。

## 验证消息的工作流（本次用到的）

1. 360搜索：`https://www.so.com/s?q=关键词`
2. 认准权威信源：央广网、证券时报、新浪财经、同花顺、天天基金（多源交叉）
3. 提取关键数字核对：日期（申购日/询价日）、金额（募资/发行价）、代码
4. 与用户截图内容逐项比对，不一致要指出
5. **募资额务必查实际值**：注册批文写的（295亿）≠ 实际募资（579亿）——影响"吸血强度"判断
