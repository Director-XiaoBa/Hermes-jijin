# 基金系统自进化机制

## 三条独立学习线

| 线 | 谁的 | 数据表 | 验证时机 |
|:--|:--|:--|:--|
| **AI预测线** | 我的分析和预测 | predictions | 15:50复盘验证昨天的预测 |
| **用户操作线** | 用户自己的交易决策 | trades.user_reasoning | 15:50评估近期操作盈亏 |
| **KOL线** | 老道等第三方推荐 | kol_tracking | 有推荐时记录+后续验证 |

### 核心原则
- 三条线**独立验证，不混淆**：我的错是我的，用户操作是用户的，老道的是老道的
- 用户参考我的分析但**自己拍板**，我只需要帮他验证对错
- 老道是**独立验证对象**，跟踪他准不准但不盲从

## 自进化闭环

```
14:00 做预测 → 写入predictions表（accuracy=pending）
15:50 验证昨天的预测 → 更新predictions + 写入improvement_log
月底 统计正确率 + 分析错误模式 → 写入monthly_stats
月底 根据统计结果 → 自动修改skill/prompt规则
下个月 执行新规则 → 重复循环
```

### 关键：15:50验证的是昨天的预测
- 14:00做预测 → accuracy=pending
- **15:50只查 prediction_date < CURDATE() 的pending预测**
- 今天的预测要等明天或更晚才能验证
- time_horizon决定验证时间：1d=隔天，3d=3天后，5d=5天后

### 数据表
| 表 | 用途 | 写入时机 |
|:--|:--|:--|
| predictions | AI预测+验证结果+教训 | 14:00写入，15:50验证 |
| improvement_log | 结构化教训清单 | 15:50写入 |
| monthly_stats | 月度正确率+错误模式 | 月底写入 |
| kol_tracking | KOL推荐跟踪 | 有推荐时写入 |
| trades.user_reasoning | 用户操作依据 | 用户操作时写入 |

## 分析范围四维度清单

每次给出买入/卖出建议前，必须覆盖：

| 维度 | 必须检查的内容 |
|:--|:--|
| **① 催化剂分析** | 核心变量→产业链→标的匹配→弹性排序 |
| **② 宏观环境** | 今晚/明天有无重大事件？美联储信号？外围风险？ |
| **③ A股位置评估** | 目标板块昨天涨了多少？是否已price in？距MA20多远？ |
| **④ 时机检查** | 大阳线日？重大事件前夜？连涨后？美股隔夜大涨？ |

## 买入时机铁律

| 检查项 | 不通过=不买 |
|:--|:--|
| 大阳线日（板块涨>3%） | ❌ 已price in |
| 重大事件前夜（杰克逊霍尔/FOMC/CPI） | ❌ 不确定性高 |
| 连涨≥3天 | ❌ 获利盘压力大 |
| 美股隔夜大涨 | ⚠️ A股高开低走概率高 |
| 美联储鹰派信号 | ⚠️ 科技股承压 |

**下单前必须回答：如果明天跌3%，我能接受吗？如果不能→今天不买。**

## 盘中估值（ETF实时估算）

盘中基金净值未发布时，用ETF实时数据估算今日涨跌：

```python
ETF_MAP = {"588200":"科创芯片", "562500":"机器人", "516150":"稀土", "159638":"数字经济", "512480":"半导体"}
# 拉ETF实时价格 → 计算涨跌% → 作为基金盘中估算参考
```

### 数据来源区分
| 数据 | 来源 | 时间 | 说明 |
|:--|:--|:--|:--|
| 基金净值 | 天天基金API | 收盘后发布 | 确认值，T日收盘后才出 |
| 盘中估算 | ETF实时（腾讯API） | 盘中实时 | 参考值，大差不差 |
| 重仓股实时 | 腾讯/新浪API | 盘中实时 | 参考值 |

**14:00报告必须区分"昨日净值"和"今日盘中估算"，不能混淆。**

### 持仓基金表格格式（v1.9 08-28定稿）

| 基金 | 当前市值 | 今日估算 | 当前累计 | 手续费 | 信号 |
|:--|:--|:--|:--|:--|:--|

**计算规则**：
- **当前市值** = 买入额 × (1 + 当前累计%)，T+1未出净值的显示买入额+T+1标注
- **今日估算** = ETF估算涨跌% × 买入额，显示百分比和金额（↓-2.41%/-¥24）
- **当前累计** = 昨日累计 + 今日估算，显示百分比和金额（≈-0.03%/-¥0.3），T+1写"待确认"
- **手续费** = 当前市值 × 费率，显示费率+持有天数+金额（1.5%(4天)/-¥7.7），满7天显示0%
- **信号** = 从信号共振分析获取
- **最后一行为合计行**，汇总当前市值、今日估算金额、当前累计金额、手续费总额
