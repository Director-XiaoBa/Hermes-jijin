# 同板块基金横向对比方法论

> 08-25 实战产出：用户问"CPO基金哪只最好"、"机器人基金要不要换"时的标准工作流。

## 触发条件
- 用户问"XX板块哪只基金最好" / "要不要换一只" / "有没有更好的"
- 用户想加仓某方向但不确定选哪只

## 对比框架（五维度）

### 1. 纯度（持仓重合度）
- 拉每只基金前十大重仓股，看目标方向（如CPO）的占比
- **纯度越高=越贴合主题**，但波动也越大
- 例：025422和008327都是纯CPO（中际旭创/新易盛），019072是广义通信（纯度低）

### 2. 收益表现（核心筛选指标）
| 指标 | 拉取方式 | 优先级 |
|:--|:--|:--|
| 近1年收益 | pingzhongdata 250日 | ⭐⭐⭐⭐⭐ |
| 近90日收益 | pingzhongdata 90日 | ⭐⭐⭐⭐ |
| 近30日收益 | pingzhongdata 30日 | ⭐⭐⭐ |
| 距90日高点回撤 | (最新/最高-1)*100 | ⭐⭐⭐⭐ |

**铁律：同板块选近1年收益最高的。** 008327近1年+131.7% vs 025422的90日才+9.5%，差距明显=008327更强。

### 3. 波动率（风险调整后收益）
- 30日日收益标准差：`sqrt(Σ(r_i - r_avg)² / N)`
- 最大单日涨/跌
- **波动率低+收益高 = 风险调整后最优**
- 例：008327波动率4.87% < 025422的6.04%，且收益更高 → 008327更优

### 4. 规模与流动性
- 规模>50亿为优（大额申赎冲击小）
- 规模<10亿需谨慎（清盘风险/大额赎回冲击净值）

### 5. 费率结构
- C类≥7天0费 = 短线友好
- A类持有<30天高费 = 不适合波段

## 输出格式（对比表格）

```
| | 基金A | 基金B | 基金C |
|:--|:--|:--|:--|
| 本质 | 纯XX | 纯XX | 广义XX |
| 股票仓位 | XX% | XX% | XX% |
| 基金规模 | XX亿 | XX亿 | XX亿 |
| 距90日高 | -XX% | -XX% | -XX% |
| 近1年 | +XX% | +XX% | +XX% |
| 30日波动率 | XX% | XX% | XX% |
| 主题纯度 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ |
```

## 结论模板
**"XX方向选A不选B，近1年+XX%就是最强证据。"**

## 已验证案例
- **CPO方向（08-25）**：008327 > 025422 > 019072
  - 008327近1年+131.7%，波动率更低，规模最大
  - 025422虽然纯CPO但收益远不如008327
  - 019072是ETF联接（股票仓位仅3.5%），不适合波段
- **机器人方向（08-25）**：018345 > 020973 > 020894
  - 018345近1年-1.4%（最抗跌），其他亏8~10%
  - 不用换，018345已是最优选
