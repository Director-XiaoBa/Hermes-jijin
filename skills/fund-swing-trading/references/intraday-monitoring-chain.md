# 盘中形态与自动盯盘链（08-05 确立）

## 一、盘中形态六式——买卖确认开关

盘中形态 = 用户的"买卖确认开关"，只解决"今天15:00前动不动手"，不预测明天。

| 形态 | 特征 | 含义 | 空仓操作 | 持仓操作 |
|---|---|---|---|---|
| 低开高走 | 开盘跌→逐步拉回 | 承接强，恐慌被买走 | ✅可买（见底信号） | ⏸️不急着跑 |
| 高开低走 | 开盘涨→尾盘跌回 | 资金在跑，趁高派发 | ⛔别买 | ✅赶紧卖（反弹可能终结） |
| 低开低走 | 开盘跌→一路阴跌 | 恐慌延续，无承接 | ⛔别接飞刀，等企稳 | 🔴破止损线就卖，没破拿住 |
| 高开高走 | 开盘涨→越走越强 | 强势确认 | ⛔别追高（大阳线日只卖不买） | ✅正好是+7%卖点，考虑落袋 |
| 冲高回落 | 盘中冲高+X%→尾盘只剩+Y% | 上方抛压重 | ⛔别进 | ✅卖（抛压重=卖点信号） |
| 探底回升 | 盘中砸新低→尾盘拉回 | 有资金低位接 | ✅可能见底，结合门槛看 | ⏸️拿住 |

进阶理解：**冲高回落=资金在跑**（早盘+7%→尾盘+3%是获利了结）；冲高回落日+次日单边下行=单边下跌趋势起点，反弹要等更久。

## 二、盯盘节奏（场外基金专属）

场外基金只能15:00前下单、按当天净值成交 → 盘中形态是帮你决定"今天15:00前要不要动手"：

| 时间 | 看什么 | 作用 |
|---|---|---|
| 9:30-10:00 | 开盘形态 | 定今天基调（高开/低开？） |
| 10:00-14:00 | 方向是否延续 | 不用一直盯 |
| 14:00-15:00 | **尾盘形态** | **最关键——决定今天是否下单** |

核心原则：**决策集中在14:30-15:00做**。前面都是观察，尾盘才是行动。

盘中形态与v1.1策略的两个接口：
1. 进场"追加确认" = 低开高走 / 不再创新低 / 板块逆势翻红 → 才动手买
2. 卖出"冲高回落锚" = 盘中冲高+X%尾盘只剩+Y% → 卖

### 14:00扫描三层宏观感知（v1.7新增，08-28教训）

**之前的问题**：只看催化剂（英伟达利好→存储受益），没看宏观环境（杰克逊霍尔/加息信号/A股已暴涨位置），导致时机错误。

**三层感知体系**：
```
Layer 1：日历预知（提前1-4周）
  → 查 ~/user_files/documents/宏观事件日历.md
  → FOMC/CPI/财报日/IPO/政策会议

Layer 2：快讯突发（实时）
  → 扫东财7x24快讯
  → 官员讲话/政策变化/地缘冲突

Layer 3：盘面反推（当天）
  → 看板块异常异动
  → 黄金暴涨=地缘风险？板块暴跌=有未知利空？
```

**分析必须覆盖4个维度（缺一不可）**：
1. 催化剂分析（核心变量→产业链→标的匹配→弹性排序）
2. 宏观环境（三层感知结论）
3. A股位置评估（昨天涨了多少？连涨几天？距MA20多远？）
4. 时机检查（大阳线日？事件前夜？连涨后？→不通过不推荐买入）

## 四、坑点（已踩过）

1. 🔴 **14:00任务必须写决策日志**：14:40尾盘确认靠读日志判断"今天有没有操作建议"。不写→14:40读到的还是昨天的判断→误判"无操作"→静默→**尾盘确认形同虚设**。日志格式必须固定（日期+盘面+触发检查+判断+深跌预警），14:40按格式解析。
2. 🔴 **复盘任务持仓以台账为准**：旧15:20任务硬编码盯017470/012738，但017470已在07-30清仓转017811——盯已清仓的基金输出全是噪音。每轮任务第一步读台账拿最新持仓。
3. 14:40任务设计为"无操作静默"——避免每天打扰用户；但这也意味着它依赖14:00写日志的可靠性，链上任何一环断掉，静默会掩盖问题。
4. 用户早上不用盯盘：9:30-10:00、盘中都不用管，14:00收简报、14:40收最终指令、15:00前执行。给用户讲清楚分工，别让他觉得还得自己盯。
5. 🔴 **分析面太窄=决策质量差（08-28教训）**：只看催化剂（英伟达利好→存储受益）没看宏观环境（杰克逊霍尔/加息信号）和A股位置（前一天已暴涨4.5%），导致方向对但时机错。**14:00扫描必须覆盖4个维度：催化剂+宏观环境+A股位置+时机检查，缺一不可。** 详见 `references/2026-08-28-analysis-scope-lesson.md`。
6. 🔴 **用户下单时必须挑战（08-28教训）**：我11:00说了"不追"，用户14:57下单后我直接确认执行。**用户决策和我之前的建议矛盾时，必须先问"为什么改主意了"，而不是默认用户考虑清楚了。**
7. 🔴 **14:00报告持仓表格式（08-28定稿）**：表头=当前市值 | 今日估算 | 当前累计 | 手续费 | 信号。所有数值由脚本预计算，agent只展示不做计算。详细规范见 `references/14-scan-report-format.md`。
8. 🔴 **T+1基金不能输出历史涨跌（08-28教训）**：脚本输出"T+1未出净值"时不能附带买入前的NAV历史，否则agent会把历史数据填入报告。T+1基金只输出状态标记，不附历史。
9. 🔴 **ETF数据必须在持仓计算之前拉取（08-28教训）**：持仓当前累计需要ETF估算值，ETF在持仓之后拉取→etf_estimates为空→所有今日估算显示"—"。

## 五、执行流程（v1.1全流程）

```
① 大势开关（科创50 20日线方向）
② 看到连续暴跌 → 查累计跌幅（≥-10%或单日≥-8%）
③ 够 → 查消息面（催化剂线索，未核实不进场）
④ 三重确认 + 14:30尾盘确认 → 15:00前申购
⑤ 持仓期每天14:50查四锚+止损（收盘净值口径）
⑥ 锚到 → 赎回 → 记录 → 等下一轮
⑦ 连亏3笔 → 暂停一周
```
