# 基金形态模式识别：暴涨后闪崩（Parabolic Rise → Sharp Drawdown）

## 定义

基金净值曲线在一段时期内（3-6个月）经历**非线性的加速暴涨**，随后在短时间内（2-4周）**急速回撤30%+** 的形态。典型如大摩数字经济混合A(017102)：从低点1.187→高点5.26（+343%），然后一个月内跌回3.54（-32.8%）。

## 识别信号

| 信号 | 表现 | 权重 |
|------|------|------|
| 近1年涨幅异常大 | >+100%（远超同类平均值+20%） | ⭐⭐⭐ |
| 1个月内回撤幅度 | 从高点跌-25%~-35% | ⭐⭐⭐ |
| 稳定性评分低 | 天天基金稳定性评分<60/100 | ⭐⭐ |
| 规模暴增 | 最近一个季度规模翻倍（散户追涨涌入） | ⭐⭐⭐ |
| 个人持有为主 | >95%个人持有，机构几乎空仓 | ⭐⭐ |
| 重仓单一赛道 | 集中押注AI/芯片/数字经济等热门主题 | ⭐⭐ |
| 基金经理进攻型 | 收益率评分>90但抗风险<75 | ⭐⭐ |

## 为什么会发生

1. **热门赛道加速上涨** → 媒体+大V渲染 → 散户追涨涌入
2. **基金规模暴增** → 基金经理被迫高位加仓（船大难掉头）
3. **赛道热点切换或利空** → 获利盘兑现 → 踩踏式下跌
4. **散户套牢** → 规模反而维持在高位（因为散户不割肉）

## 分析此类基金时的关键问题

### 已持有者问怎么办

| 问题 | 回答方向 |
|------|---------|
| 跌了30%了，要不要割？ | 看当前位置是否已企稳：周线是否不再创新低？成交量是否萎缩？如果还在加速跌（如一周跌10%），说明抛压未释放完，建议继续观望或减仓 |
| 等反弹再卖？ | 历史数据表明闪崩后通常有技术性反弹（10-15%），但二次探底概率>50%。反弹是减仓窗口，不是加仓时机 |
| 跟我的XX基金比谁更抗跌？ | 拉两只基金同时段的数据对比：同一起点→高点涨幅比→回撤幅度比→反弹力度比 |

### 未持有者问能不能抄底

| 问题 | 回答方向 |
|------|---------|
| 现在是不是便宜了？ | 区分"从高点跌了很多"和"估值合理"。跌了33%但可能只回到了合理估值区，不是便宜 |
| 能不能抄底搏反弹？ | 等企稳信号出现再考虑：周线收阳、不再创新低、成交量极度萎缩。此时抄底风险仍大 |
| 定投行不行？ | 如果看好赛道长期逻辑，可以小额定投。但闪崩后通常需要2-3个月筑底 |

## 实盘案例：大摩数字经济混合A(017102)

**基金档案：**
- 成立：2023-03-02 | 基金经理：雷志勇（7年经验）
- 类型：混合型（股票仓位92.44%）
- 管理费：1.50%

**暴涨阶段（2025-04 ~ 2026-06）：**
- 低点：1.1871（2025-04-08）
- 高点：5.2606（2026-06-25）
- 涨幅：+343%（1年+136%）
- 规模从23.86亿 → 134.71亿（最近季度+192%）

**闪崩阶段（2026-06-25 ~ 2026-07-28）：**
- 从5.2606 → 3.536（-32.78%）
- 近1月：-28.21%
- 近1周：-10.33%（还在加速）

**业绩评分：**
| 维度 | 分数 | 含义 |
|------|:----:|:----|
| 收益率 | 100 | 涨的时候无可挑剔 |
| 选证能力 | 85 | 选股不错 |
| 择时能力 | 80 | 择时还行 |
| 抗风险 | 70 | 回撤控制一般 |
| 稳定性 | **55** | 🔴 波动极大 |

**对比同赛道：** 017102 vs 017811（东方人工智能）
- 017102 3.536 vs 017811 3.537 ≈ 同一价位
- 两者都是数字经济/AI主题，跟踪不同指数
- 用户之前判断017811在3.537太贵（71%分位），017102同理

**数据来源：天天基金pingzhongdata API（2026-07-28）。**
