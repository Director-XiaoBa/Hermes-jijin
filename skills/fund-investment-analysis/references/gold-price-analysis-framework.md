# 黄金价格分析框架

## 三种价格口径（务必区分）

| 口径 | 说明 | 投资/消费场景 |
|:---|---|:---|
| **国际现货黄金**（XAU/USD） | 伦敦金，美元/盎司 | 黄金ETF、国际投资者参考 |
| **国内现货大盘价**（原料金） | 上海金交所/银行金条基准价，¥/克 | 投资金条、积存金 |
| **品牌金饰零售价**（周大福/老凤祥等） | 含品牌溢价+工艺费，¥/克 | 自用/结婚购置金饰 |

> 金饰零售价 = 原料金 + 品牌溢价(15-30%) + 工艺费
> 通常比原料金贵 ¥300-500/克

## 黄金ETF（518880）专项分析

### 关键概念：净值（NAV） vs 交易价格

| 概念 | 说明 | 获取方式 |
|:---|---|:---|
| **净值 NAV**（单位净值） | 基金持有的实物黄金的公允价值，每股约对应0.01克黄金 | `pingzhongdata/518880.js` 中的 `Data_netWorthTrend` |
| **交易价格** | 二级市场买卖价格，由供需决定 | 实时行情：`hq.sinajs.cn/list=sh518880` |
| **溢价/折价** | 交易价 > 净值 = 溢价，说明市场情绪偏热 | 计算：(交易价/净值-1)×100% |

### 溢价/折价作为情绪信号

| 溢价率 | 信号 | 含义 |
|:-----:|:---|---|
| >1% | 🔴 情绪过热 | 市场追买，适合等待而非入场 |
| 0%~1% | 🟡 中性偏热 | 正常波动，可持有但非最佳买入点 |
| <0% | 🟢 折价 | 情绪偏冷，可能是相对好的介入位置 |

> 示例：2026-07-27 交易价8.477 vs 净值8.4129 → 溢价0.76%，中性偏热信号。

### 基金价格 vs 国内现货金价换算

518880 净值 × 100 ≈ 国内金价（元/克）
- 净值8.4129 → 隐含金价 ≈ 841 元/克
- 交易价8.477 → 隐含金价 ≈ 848 元/克

### "金价一直高位"感知偏差分析

当用户说"金价一直居高不下"、"最低也就X.XX"时，常见感知偏差：

**偏差1：以最新价格锚定历史区间**
- 用户感知的"最低"往往是近期反弹高点，而非真实最低
- ✅ 修复：拉取近30日净值数据，标注真实的最低/最高/当前三条线

**偏差2：只看价格不看溢价**
- 用户看到交易价8.477 → "还是这么贵"
- 但净值可能只有8.41，实际金价没涨那么多
- ✅ 修复：区分交易价和净值，溢价部分说明市场情绪

**偏差3：认为波动"窄"**
- 用户感觉金价"不动"，因为看的是绝对值（8.4~8.9 觉得差0.5"很小"）
- 但对于黄金，8%的月波幅已经属于活跃区间
- ✅ 修复：用百分比而非绝对数表示波幅

**分析流程（用户说金价高位/不动时）：**
1. 拉30日净值数据 → 找真实最低/最高
2. 计算当前交易价溢价率 → 判断市场情绪
3. 计算近30日真实波幅（%）→ 与用户感知对比
4. 对比用户说的"最低"和实际最低 → 指出感知偏差
5. 输出完整分析：当前周期位置+溢价信号+定投建议

> **黄金不是基金**，买黄金不等于买黄金ETF或基金。用户的投资能力圈是场外C类指数基金，黄金相关没有C类指数基金可买，所以：
> - 想买实物金→银行金条/积存金
> - 想买黄金ETF→是场内产品，需要证券账户（用户不炒股，不推荐）
> - 用户问"黄金能不能买"时，应该给具体的价格区间建议，而不是推荐黄金基金
