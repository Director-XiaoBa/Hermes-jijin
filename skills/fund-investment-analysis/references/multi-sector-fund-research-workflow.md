# 多方向基金调研工作流

当用户问"下半年有什么方向/基金推荐"时，按此流程并行调研。

## 流程

### 1. 确定方向
从机构研报/市场热点中提取3-6个方向：
- 半导体/AI（用户已有）
- 创新药
- 稀土/有色
- 银行/高股息
- 商业航天/军工

### 2. 并行查找基金代码（推荐用 delegate_task）
针对每个新方向，用 delegate_task 分配子任务并行查代码：
- 每个子任务查找：该方向的C类场外联接基金代码、成立时间、规模、跟踪指数
- 推荐使用天天基金(https://fund.eastmoney.com/) 或 360搜索 查询
- 每方向最多推荐2只（1首选+1备选），不列长清单

### 3. 汇总+排序
- 对比各方向的机构逻辑说服力
- 对比用户已有持仓
- 按推荐优先级排列

### 4. 输出格式
```
### ⭐⭐⭐ [优先级] [方向名称]
| 推荐基金 | 代码 | 逻辑 | 时机 |
|:---|---|:---|---:|

### 操作路线图
1. 第一步（XX前）：...
2. 第二步（XX后）：...
3. 第三步（等XX后）：...
```

### 数据来源
- 天天基金网 fund.eastmoney.com — 基金代码、规模、成立时间、跟踪指数
- 360搜索 so.com — 机构观点、市场分析
- 基金持仓台账 — 用户已有持仓
