# 波段交易双模式回测（2026-07-31 产出）

> 数据源：017470 嘉实科创芯片ETF联接C，全量884个交易日净值（2022-12-07 ~ 2026-07-30），天天基金 pingzhongdata API。
> 背景：韩股熔断暴涨（SK海力士+27%/三星+20%）当天，用户提出"连续暴跌后暴涨→抄底赚差价"的思路，用全量数据回测验证。

## 核心结论

**用户的直觉方向对，但必须严格参数化执行：**
1. 跌-6%就抄底胜率只有67%且经常套30天；**跌-10%才动手胜率83%、平均持有13天**
2. 必须带止损（-5%）+ 超时（30日），否则"等暴涨等到天荒地老"的深套会污染收益
3. 必须算赎回费：C类持有<7天赎回费1.5%，暴涨日卖出净赚>6%才值得卖

## 铁律：大阳线当天只卖不买

| 案例 | 操作 | 结果 |
|:---|:---|:---|
| 2026-07-09 超跌反弹暴涨+8.4% | 追入 | 10天亏21.5% ❌ |
| 2026-07-21 暴跌后暴涨+12.6% | 提前抄底（07-14进场太早） | 反而亏8% ❌ |
| 2026-07-30 触发-10%信号 → 07-31暴涨 | 进场后暴涨日卖出 | 净赚+6.5% ✅ |

## 模式A：暴跌抄底（短线差价）

| 参数 | 值 |
|:---|:---|
| 触发 | 连续3日累计跌幅 ≤ **-10%** |
| 进场 | 触发当天14:50前申购（按当日净值） |
| 止损 | 进场后亏 **-5%** 无条件卖出 |
| 止盈 | 单日涨 ≥ **+5%** 卖出（<7天扣1.5%费后净赚>6%才值得） |
| 超时 | 30个交易日不涨不跌 → 走人 |
| 仓位 | 单笔 ≤ 总资金 10-15% |
| 历史表现 | 6笔5盈1亏，平均净收益+6.88%，平均持有13天 |

### 关键坑点
- **暴跌初期抄底被连扇耳光**：2026-07-14/07-16连续触发信号，买入后继续跌，-5%止损连吃两次亏（-6.6%、-9.5%），直到07-20第三次触发才吃到07-21的暴涨。→ 触发后如果继续跌，止损后等下一轮信号，不要"扛"。
- **无外部催化的暴跌可能是阴跌不止**：07-21暴涨和07-31暴涨都有外部消息（AI存储/HBM），纯超跌反弹的暴涨胜率低。

## 模式B：趋势追涨（吃趋势段）

| 参数 | 值 |
|:---|:---|
| 进场 | 趋势确认（20日均线上方）+ 回调企稳后买入 |
| 铁律 | 大阳线当天不追 |
| 卖出 | 持有到趋势破位（跌破20日线） |
| 止损 | -8%~-10% |

### 暴涨位置决定生死（追入后10天表现）

| 暴涨类型 | 次数 | 追入10天平均 | 赚钱概率 |
|:---|:---:|:---:|:---:|
| 📈 趋势中暴涨 | 12次 | +6.9% | 58% |
| ➡️ 震荡后暴涨 | 6次 | +11.0% | **83%** |
| ⚡ 超跌反弹暴涨 | 5次 | **-1.5%** | **40% ❌ 不能追** |

### 为什么"趋势中暴涨"能追、而"超跌反弹暴涨"不能追
- 2026-06 趋势段：底部2.72 → 一个月涨到3.89（+43%），中间6次+4%以上大阳线，每次回调1~2天继续涨 → 趋势中暴涨=加速器
- 2024-09 疯牛段：底部0.75 → 4天暴涨55% → 可遇不可求
- 2026-07-09 超跌反弹暴涨 → 之后10天跌21.5% → 反弹是逃命波

## 数据特征统计

- 单日涨≥5%：884个交易日仅24次（2.7%）
- 单日跌≤-5%：16次（1.8%）
- 连涨天数分布：1天121次、2天49次、3天29次、4天14次、5天6次、6天4次、7天4次 → **连涨≥5天仅6%，"一直涨"是稀有事件**
- 暴跌后第一根+5%大阳线：5次样本中2真3假（2024-02-06真、2025-09-11真；其余假）→ 第一根大阳线不能确认底部
- 连跌3天后小阳线（+1%~+4%）次日上涨概率仅56% → 无信号价值

## 操作决策模板（大阳线日的判断）

指数盘中涨幅 ≥5%（科创芯片/科创50等）→ 判定大阳线日：
1. 持仓者：到止盈线就卖；没到止盈线（如017470成本3.14、估值2.82）继续持有，不割肉
2. 空仓者：**今天绝对不能追**，等下一轮暴跌信号（-10%触发），或趋势回调企稳
3. 已触发-10%信号且已进场：暴涨日卖出吃波段（净赚>6%才值得，因<7天扣1.5%费）
