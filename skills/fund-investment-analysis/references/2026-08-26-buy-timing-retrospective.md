# 买入时机复盘分析方法论（2026-08-26 实案）

## 场景触发
用户说"我是不是买入时机不对，买完就大跌了"——自我怀疑型复盘请求。

## 分析框架：5步买入时机诊断

### Step 1: 拉买入前后走势（核心数据）
用MySQL `nav_daily` 拉每只持仓基金买入前5日~买入后至今的净值+回撤+RSI+趋势：
```sql
SELECT fund_code, trade_date, nav, daily_return, drawdown_from_high, rsi_6, trend
FROM nav_daily WHERE fund_code IN (...) AND trade_date BETWEEN '买入前5日' AND '今天'
ORDER BY fund_code, trade_date;
```
**重点标记**：买入日当天的市场状态（是暴跌中/企稳日/反弹日？）

### Step 2: 构建市场事件时间线
| 日期 | 事件 | 影响 |
|:---|:---|:---|
| T-2 | 暴跌日（各基金-5%~-10%） | 市场恐慌 |
| T-1 | 止跌企稳 | 初步筑底 |
| **T（买入日）** | **用户买入** | 微涨0.1%~1.6% |
| T+1 | 二次下杀 | 再跌-3%~-5% |
| T+3 | 企稳反弹 | 反弹+0.5%~+2.4% |

### Step 3: 逐只诊断评分
每只基金给一个"买入时机评分"（50-100分），维度：
- 买入价距当时低点的距离（越近越好）
- 买入后最大回撤（越小越好）
- 当前离回本的距离（越近越好）
- 信号来源权重（老道/自主/跟风）

### Step 4: 区分"时机问题" vs "品种问题"
**关键洞察**：用户说"买完就跌"，但真问题往往不是时机，而是品种选择。

| 诊断维度 | 时机问题 | 品种问题 |
|:---|:---|:---|
| 特征 | 买在高点，卖在低点 | 买的品种本身弱，大盘涨它不涨 |
| 证据 | 买入后连续阴跌 | 同期同类基金涨幅明显更高 |
| 修复 | 等更低点再买 | 换到更强的品种 |
| 本次实案 | 整体亏-1.15%，不算深套 | 018123弱势品种拖累整体 |

### Step 5: 给出可操作建议
- 短期：当前持仓离回本多远？需不需要止损？
- 中期：是否需要调整持仓结构（砍弱留强）？
- 长期：下次买入前的检查清单改进

## 实案关键教训（2026-08-26）

### 品种选择比时机更重要
- 08-21买入4只基金（017470/011036/018345/018123），08-25买入1只（017811）
- 08-24遭遇二次下杀，但08-26反弹后：
  - 强品种（017811）已盈利+2.38%
  - 弱品种（018123）仍亏-3.13%
- **结论：同样的买入时机，不同品种结果天差地别**

### 买入时机评分标准
| 评分 | 含义 | 典型场景 |
|:---|:---|:---|
| 85+ | 优秀 | 在恐慌下跌中逆向买入，次日反弹 |
| 70-84 | 良好 | 暴跌后企稳日买入，遇到二次探底但已反弹 |
| 50-69 | 一般 | 买入弱势品种，反弹力度弱 |
| <50 | 差 | 追高买入，持续阴跌 |
