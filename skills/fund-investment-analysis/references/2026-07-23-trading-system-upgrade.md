# 2026-07-23 交易系统升级

## 变更内容

当日对基金交易系统进行了一次完整升级，补全了三个此前缺失的机制：

### 1. 新增止盈线（每只基金独立）
- 之前：只有通用止盈规则（+10%卖一半），但没有写入台账
- 之后：台账表头新增「止盈线」列，每只基金单独列出具体数值
  - 芯片017470: +10%（~¥3.45）
  - 创新药012738: +10%（~¥0.66）

### 2. 新增补仓次数上限（每只基金独立）
- 之前：补仓没有上限，跌了就补，可能越陷越深
- 之后：台账新增「补仓上限」列
  - 芯片017470: 最多+3次（总额≤¥400），当前批次1/4
  - 创新药012738: 最多+2次（总额≤¥300），当前批次1/3
- 每批¥100，不超限

### 3. 执行铁律（硬性触发机制）
- 之前：设了线但不执行，浮盈+11%没卖，浮亏-22%才割
- 之后：止损/止盈线到价 → 我直接推送建议 → 用户确认 → 立即执行
- 禁止"等反弹"、"再看看"、"还能涨更多"

### 4. 推送信号区分
- 之前：每天推送不管有没有机会都长篇分析
- 之后：有操作→明确说"操作"，没操作→说"今天没什么要动的"

### 5. 用户现金管理纠正
- 台账删除"合计在仓¥400""现金储备¥905"字段
- cron prompt 删除"用户有充足现金"等表述
- 所有定时任务加上"不管理用户现金余额"规则
