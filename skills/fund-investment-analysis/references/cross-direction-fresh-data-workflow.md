# 多方向分析时的新鲜数据验证流程

> 2026-07-23 用户明确批评："你有去搜索和拉取数据来分析吗"——暴露了我在多方向分析时，部分方向用了新鲜数据，部分方向靠记忆/常识判断的问题。

## 正确的多方向分析流程

### 第一步：ROUND-ROBIN 数据采集

当需要分析 N 个方向时，对**每一个**方向（不只是部分）执行：

```
for each 方向 in [方向1, 方向2, ..., 方向N]:
    1. curl lsjz API → 拉最近30日净值数据
       curl -s "https://api.fund.eastmoney.com/f10/lsjz?callback=jQuery&fundCode={CODE}&pageIndex=1&pageSize=30" \
         -H "Referer: https://fundf10.eastmoney.com/"
    2. 计算: 30日最高、30日最低、最新、距高点%、距低点反弹%
    3. 360搜索/Bing搜索 → 该方向近期新闻（最近7天），提取关键催化剂
       https://www.so.com/s?q={关键词}+新闻+2026年7月
    4. 标注: 有催化剂(具体事件) / 无催化剂(确认已搜过)
```

### 第二步：逐个标注数据来源

在输出中对每个方向标注数据来源状态：

| 状态 | 含义 |
|:---:|:----|
| ✅ 新鲜拉取 | 本次会话实时curl/搜索，有截图/摘要 |
| 🔄 沿用旧数据 | ❌ 不推荐——用户可能质疑 |

### 第三步：宁可晚答，不凑合

- 如果某个方向的数据还未全部拉完 → 明确说"XX方向的数据我还在查，稍后补上"
- 不要混用"已拉数据+未拉印象"的组合输出
- 用户更接受"等一下再给你完整答案"而不是"部分正确部分猜"

## 反面案例（本次会话）

```
❌ 我做的：
   - 拉取了稀土和电池的NAV数据 ✅
   - 搜索了稀土和电池的新闻 ✅
   - 对机器人和有色金属的判断：
     * 机器人："没催化剂" ← 基于记忆，实际昨天有白皮书发布
     * 有色金属："反弹已+7.5%" ← 基于几小时前的数据

✅ 应该做的：
   - 拉取所有4个方向的NAV数据 ✅（这部分做了）
   - 搜索所有4个方向的新闻 ✅（机器人没搜→判断错误）
   - 每个方向独立给出位置+催化剂判断
```
