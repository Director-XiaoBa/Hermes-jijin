## 对比框架

| 维度 | 指数C类（如012738） | 主动股票C类（如003231） |
|:---|---|:---|
| 弹性 | 跟指数走，涨跌同步 | 集中度高（前10占71%）→弹性更大，双刃剑 |
| 短线成本（7-30天） | 0% ✅ | 0.5% ⚠️ |
| 年费率 | ~0.5% | ~2.55%（贵5倍） |
| 风险来源 | 市场系统性风险 | 市场风险+基金经理决策风险+集中度风险 |
| 适用短线 | ✅ 7天以上赎回费0 | ⚠️ 7-30天还有0.5%赎回费，不适合超短 |
| 规模安全 | 大几十亿，安全 | 2亿，迷你基金有清盘风险 |
| 最大优势 | 透明、便宜、稳定 | 涨的时候更猛（40%vs19%） |
| 最大劣势 | 涨得慢 | 跌的时候也猛（2天跌8%），贵 |

## 鱼尾行情判断

当一只基金在**14个交易日内涨超30-40%**时：
- 鱼身（最肥的部分）已经被吃了
- 鱼尾（剩下的肉）少刺多
- 追高被套的概率远大于继续吃肉的概率
- 此时建议等回调5-8%再入，而不是追高

## 短线操作纪律

| 条件 | 动作 |
|:---|---|
| 持有≥7天 | 赎回费归零，可操作 |
| 盈利≥5% | 考虑止盈（短线不贪） |
| 亏损≥3-5% | 必须止损（不拖） |
| 7天内涨超8-10% | 立刻止盈（获利盘随时砸） |
| 已经涨超30%+ | 等回调，不追（鱼尾行情） |
