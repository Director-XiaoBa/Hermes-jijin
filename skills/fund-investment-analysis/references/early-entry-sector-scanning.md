# 提前布局：市场风格切换与低位方向扫描方法论

> 来源：2026-07-22/23 会话，用户要求"早进场不吃尾气"

## 核心原则

用户说：**"我们要早进场，不能吃尾气了"**。这意味着不能等到一个方向已经爆拉才推荐，必须在板块刚启动或还在低位时就识别出来。

## 扫描流程

1. **每日全市场扫板块** → 拉所有板块涨跌排名
2. **按热度分类**：🔥🔥🔥尾气 / 🔥🔥半路 / 🔥刚启动 / 💤低位
3. **低位+有催化=重点关注**
4. **优先于用户已有方向主动推荐**
