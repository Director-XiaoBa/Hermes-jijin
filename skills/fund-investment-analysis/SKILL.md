# 基金投资分析：市场事件 → 持仓映射

# 🧠 基金分析铁律框架（与用户共同打磨）

## 💡 基础知识：A类 vs C类基金区别

用户可能问\"C类是什么\"——基础概念需要在skill里备查。

| 维度 | A类 | C类 |
|:----|:---|:---|
| 申购费 | **收**（通常0.1%~1.5%） | **0%（免费）** |
| 赎回费（<7天） | 1.5% | 1.5% |
| 赎回费（≥7天） | 通常0%（持有越久越低） | **0%** ✅ |
| 销售服务费 | 无 | 每年约0.4%~0.8% |
| 适合场景 | **长期持有（1年+）** | **短期操作（7天~数月）** |

**为什么我们一直选C类：** 短线波段（7~15天）持有满7天赎回费=0，进出自由。买的时候不花钱，卖的时候也不花钱——短期操作选C类绝对划算。

⚠️ **但是主动管理型C类（如003231）注意赎回费阶梯**：有些主动C类7~30天赎回费仍收0.5%，下单前一定要确认。

## 💡 基础知识：指数 vs 基金

用户可能问"科创50是什么""创业板是什么"这类基础概念——需要先解释清楚，再进入分析。

| 概念 | 是什么 | 跟基金的关系 |
|------|--------|--------------|
| **指数**（如科创50 sh000688、创业板 sz399006） | 一组股票的"成绩单"，反映整体涨跌 | ❌ 不是基金，不能直接买 |
| **ETF基金**（如159995半导体ETF） | 跟着指数走的基金，场内交易 | 需要股票账户才能买 |
| **联接基金**（如011613科创50ETF联接C） | 跟着ETF走的场外基金 | ✅ 用户可以买这个 |

**话术模板**（用户问"XX是什么"时）：
> "科创50是指数，不是基金。就像'上证指数'代表A股整体一样，科创50代表科创板最大的50家公司。你想买科创50的话，可以买011613华夏科创50ETF联接C，它跟着科创50走。"

**为什么重要**：用户可能把指数涨跌直接理解为某只基金的涨跌，需要明确区分。分析市场时用指数（如科创50跌6.71%），推荐买入时给联接基金代码（如011613）。

## 第一步：找到机会（怎么发现该买什么）

### 三个来源

| 来源 | 你负责 | 我负责 |
|:---|---|:---|
| 📰 **新闻/政策** | 看到了告诉我 | 核实新闻真假+分析对什么方向有利 |
| 🗣️ **博主/朋友推荐** | 截图或转述给我 | 查数据验证：位置高不高？有催化剂吗？逻辑成立吗？ |
| 🔍 **我主动扫描** | — | 每天扫全市场板块，发现低位+有催化的方向主动告诉你 |

### 判断标准：一个方向值不值得关注

```
✅ 值得关注 = 位置低 + 有催化剂
   → 位置低：从高点跌了-20%以上
   → 有催化剂：有新闻/政策/资金流入等明确理由

❌ 不关注 = 没有催化剂的位置低
   → 只是"跌了很多"，但没理由涨

🔥 已热不追 = 连续大涨多日（尾气行情）
   → 电力6连板、某板块单日+12%等
```

## 第二步：评估能不能买（决定前必查3项）

### ① 催化剂检查
| 查什么 | 具体操作 |
|:---|---|
| 今天为什么涨/跌？ | 我搜新闻、看板块排名 |
| 催化剂是真的还是炒作？ | 用官方来源交叉验证 |
| 催化剂能持续多久？ | 短期脉冲（1-2天）还是中期逻辑（几周） |

### ② 位置检查
| 位置 | 距最高 | 操作 |
|:---:|:---:|:---|
| 🟢 **低位** | -20%以下 | ✅ 可以买 |
| 🟡 **中位** | -10%~-20% | 等回调再买 |
| 🔴 **高位** | -10%以内 | ❌ 不追 |

### ③ 风险检查
| 查什么 | 说明 |
|:---|---|
| 跟现有的重复吗？ | 同一方向不买第二支 |
| 波动多大？ | 芯片这类暴脾气，止损线要设宽（-10%） |
| 最大可能亏多少？ | 算一下：¥200 × (-10%) = 亏¥20，能接受就买 |

### 🧲 特殊类型：政策/地缘博弈驱动的主题基金（如稀土、出口管制题材）

对于非基本面驱动、而是**政策/地缘政治/国家安全**驱动的主题基金，在上述三查基础上额外增加：

**④ 政策面检查**
| 查什么 | 具体操作 |
|:---|---|
| 是否有持续的政策催化？ | 查商务部/工信部等官方来源近期公告，确认政策是"一次性的"还是"持续升级的" |
| 是否已有极端涨幅？ | 稀土/出口管制题材一旦出政策容易暴涨暴跌，查近1个月是否已暴涨过 |
| 国际对手的反应？ | 美欧日等国的反制/应对措施也可能反过来打压题材 |

**⑤ 区分"政策慢变量" vs "行情催化剂"**
- 出口管制是**慢变量**——持续收紧供应→长期涨价预期，但不会明天就拉涨停
- 政策文件/新闻公告是**行情催化剂**——文本发出当天/几天内可能有脉冲行情
- 慢变量适合提前埋伏（位置低时），催化剂适合等消息出来再确认跟进
- **陷阱**：慢变量不能当短线持有理由。"政策利好"不等于"明天就涨"

**适用场景判断表：**
| 基金类型 | 驱动因素 | 分析侧重 |
|:---|---|:---|
| 有色/石油/铜铝 | 大宗商品价格 | 国际期货走势、供需数据 |
| 稀土/战略矿产 | 出口管制+地缘博弈 | 政策公告、国际反应、库存周期 |
| 芯片/半导体 | 科技周期+国产替代 | 行业景气度、大厂资本开支 |

### 三查之后，给结论

```
✅ 催化剂明确 + 🟢 低位 + ⚠️ 风险可控 = 买入
✅ 催化剂明确 + 🟡 中位 = 等回调再买
❌ 没催化剂 + 🟢 低位 = 关注不买，等催化出现
❌ 任何位置 + 🔴 已热 = 不追
```

## 第四步：怎么卖（最关键！）

### 止盈规则（赚了怎么卖）

| 盈利 | 操作 | 理由 |
|:---:|:---|---:|
| **+5%** | 可以卖，但不强制 | 短线7-15天赚5%已经不错 |
| **+10%** | **卖一半** ⚡ | 锁定利润，留一半继续涨 |
| **+15%~+20%** | **全卖** 🚀 | 落袋为安，不贪最后一口 |
| 7天内涨超+10% | 直接全卖 | 短期暴涨必然回调 |

> **每只基金的具体止盈线记录在台账中**。通用规则是+10%卖一半，但每只基金因波动性格不同可能有不同的止盈线（如芯片+10%，创新药+10%），写入台账表格的"止盈线"列。到价即触发推送执行，与止损同等待遇。

### 止损规则（亏了怎么卖）

| 跌幅 | 基金类型 | 操作 |
|:---:|:---|---:|
| **-6%** | 创新药（中波动） | 卖 |
| **-8%** | 消费电子（大波动） | 卖 |
| **-10%** | 芯片/AI（暴脾气） | 卖 |

**🔴 执行触发机制（与用户约定铁律）：**
- 止损/止盈线到价 → 我直接推送建议 → 用户确认 → 立即执行
- 禁止说"等反弹"、"再看看"、"还能涨更多"
- 禁止到了止损线还持有观望——连续暴跌-22.6%的教训不能再犯
- **止盈和止损同等待遇**：+10%到价同样触发推送，不因为"在赚钱"就犹豫

## 一句话总结整个体系

> **我负责：发现机会→数据验证→推演预测→盯止损止盈**
> **你负责：拍板买不买→告诉我操作了→到点执行卖**
> **核心纪律：买在低位+拿住等涨+到点就卖=赚钱**

这个体系已经写进skill了，以后每次分析自动按这个框架走。你觉得还有什么要调的吗？

用户明确说："也不能说死短期...得根据情况来调整"。

| 市场给什么 | 就做什么 |
|:---|---|
| 有大行情（如科技几个月牛市） | ✅ 拿着，吃整段 |
| 短期脉冲（一天涨12%） | ✅ 赚了就跑 |
| 横盘震荡 | ✅ 等方向，不动 |
| 有明确催化剂 | ✅ 进去赌一把 |
| 有风险信号 | ✅ 跑得快 |

**不是"短线交易者"或"长期持有者"——是"根据当前市场情况做最合理操作的人"。** 每次买入前想清楚：**这笔的逻辑是什么？什么时候走？**

### 🔴 用户疲劳/退出决策模式

当用户说"累了""地狱""真失败""算了不考虑了""看不到涨的证据"等表达疲惫或想退出时：

1. **先承认感受，数据佐证** — "7月确实难熬，科技板块跌了30%+，不是你的问题"
2. **检查仓位实际损失** — 往往金额很小（如¥4浮亏），明确告知：**"这不是失败，是市场整体太差"**
3. **提供干净退出方案**，不要劝留：
   - ✅ 明确说"你想退出我尊重，计划是……"
   - ✅ 区分"选错了工具" vs "选错了板块"（如017470弱但017811强 ≠ 芯片没救了）
   - ❌ 不要在这时候再推新方向或试图说服
4. **处理"博主赚钱了"的挫败感**：
   - 承认别人的短期收益是真实的
   - 但指出亏损根源是**入场时机不对**（追在了大涨尾巴），不是判断力问题
   - 给出"清仓换方向"的明确步骤，不要让人带着挫败感还留在市场里
5. **最终话术结构**：共情 → 实际损失数据 → 两个选项（保本清仓/等反弹清）→ 让用户选

### 用户学习进步信号：正确纠正时的处理

当用户主动纠正你的判断（如"你选的这个涨太多了，那个在低位更安全"），并且说"没想到这次是我来纠正"时：

1. **立即承认** — 用户是对的，尊重其成长
2. **复盘偏差原因** — 你在分析里忽略了什么？为什么？
3. **记录到 skill** — 把这次偏差的原因写入pitfall，防止再犯
4. **鼓励正向循环** — 用户的视觉判断（看K线/看走势）和你的数据分析能力可以互补

**特别信号：用户提到K线/蜡烛图/走势线时**
- 说明用户开始看图自学了，主动将图表语言转化为分析判断
- 这是进步信号——用户从被动听判断，转向主动看图表
- 在分析中主动引入K线位置分析（距30日高点、距低点反弹幅度、是否连续阳线等），帮助用户建立"价格位置"的直观认知

### 🔴 铁律：不管理用户现金余额

**用户明确要求：不要记忆、管理、假设用户的现金余额。** 用户的钱是流动的，不会实时同步。

- 台账中**不记录**「现金储备」「总资产」「可用余额」等字段
- 推荐金额时用建议语气（如「建议¥200起步试水」），不要说「你只有XX元」
- 即使用户之前说过金额也不当作固定资金上限
- 各定时任务（cron job）prompt 中不得写「用户有XX现金」「用户资金X元」
- 只记录每笔买入的确认金额，不汇总「还剩多少钱」

## 推送/分析的标准输出格式

每次14:00推送或用户问方向时，按此格式输出：

## 🔴 Pitfall: "你说反弹要来，但又不让加仓" — 持仓深跌时的矛盾处理

当用户持仓深跌（-10%+）后问"能不能加仓平摊成本"，而你既认为反弹快来了又建议不加仓时，用户大概率会抓住这个矛盾：

> 用户："你不是说感觉要到反弹点了吗？那我加仓为什么不行？"

**这个矛盾是对的——必须立刻承认，不能辩护。**

### 核心原理

| 概念 | 含义 | 风险等级 |
|:----|:----|:--------:|
| **持有不动（死扛等反弹）** | 已有亏损不再加码，等反弹减亏出局 | 🟡 **低风险** — 已有浮亏，再跌也就那样 |
| **加仓抓反弹（主动买）** | 在下跌趋势中增加暴露，博取更大弹性收益 | 🔴 **高风险** — 判断对了解套更快，错了亏损翻倍 |

**这两件事的盈亏结构完全不同：**
- 持有不动 = 已经亏了那么多，不加码就不会扩大亏损
- 加仓 = 你在用新钱赌反弹，判断错了亏损翻倍

### 处理流程

**Step 1: 立刻承认矛盾**
> "你说得对，我确实说了反弹快来了。那我刚才的话就有矛盾——我说反弹要来→你说那加仓→我说不行，这逻辑是拧巴的。我重新理一遍。"

**Step 2: 拆成两种选择，各自算清盈亏**
不要只说"不行"，要摆清楚两种选择的逻辑和风险：

| 选择 | 逻辑 | 你赚什么 | 你亏什么 |
|:----|:----|:--------|:--------|
| **A. 不动** | 你有仓位在，反弹来了你本来就赚 | 减亏15%→5%，不再额外冒险 | 反弹来了一样赚，只是没翻倍 |
| **B. 加仓** | 你在赌反弹力度够大 | 反弹来了，成本拉低解套更快 | 判断错了，仓位×2，亏损从15%变25% |

**Step 3: 给概率+情景**
用两个情景对比，让用户自己判断值不值得：

```
如果现在加仓：
🟢 乐观情境（65%）：反弹到3.0 → 加仓部分赚~10%，成本拉低到~2.9，全部解套
🔴 悲观情境（35%）：继续跌到2.4~2.5 → 总仓位×2，亏损扩大到20%+

那个35%的概率，对应的是基本面中期压制（加息预期、存储周期），不是短期情绪。
```

**Step 4: 如果用户还是想加，给约束条件**
- ⚠️ 控制金额：最多加到原有仓位的一半，别翻倍
- ⚠️ 设时间限制：反弹到了目标就全部出，不等更多
- ⚠️ 设止损：如果下周继续跌超5%，加仓部分直接割

### 判断标准：什么时候可以同意加仓

| 条件 | 可以 | 不可以 |
|:----|:---:|:------|
| 原策略是"反弹就卖，退出板块" | — | ❌ 方向反了 |
| 原策略是"这个方向长期看好，只是等买点" | ✅ 可加 | — |
| 下跌是情绪性/事件性（非基本面） | ✅ 可加 | — |
| 下跌是基本面/周期转向 | — | ❌ 越加越亏 |
| 用户明确说"我就博短线反弹，快进快出" | ✅ 可加但控仓 | — |

### 关键话术点
- 不说"不行"就结束 — 要解释为什么不行
- 要用"两个方案自己对比"的方式呈现 — 让用户看到选择自由
- 如果用户坚持要加（且条件允许），给出明确约束而不是继续劝

## 📊 策略回测验证工作流（用户提出交易思路时）

当用户提出"我是不是可以这样抄底/这样波段/这样赚钱"之类的策略想法时，**不要直接认可或否定**，用全量历史数据回测验证（用户期待"一起总结经验一起进步"的协作模式）：

### Step 1：拉全量净值
pingzhongdata 的 `Data_netWorthTrend` 有全部历史（017470有884个交易日，2022-12至今），足够回测。

### Step 2：定义策略参数并回测
- 触发条件（如连续3日累计跌幅 ≤ -6%/-8%/-10%）→ **对比不同阈值的胜率/平均收益/平均持有天数**，阈值越高（跌得越狠）胜率越高
- **必须带止损**（如 -5%）和超时（如30日），否则"等暴涨等到天荒地老"的深套会污染结果
- **必须算费率**：先查赎回费（fundf10.eastmoney.com/jjfl_{code}.html），C类基金持有<7天赎回费1.5%，短线利润会被费率吃掉，小赚变亏
- 关键输出：胜率、平均净收益、平均亏损、平均持有天数、最大单笔亏损

### Step 3：挖隐藏点（回测之外的统计分析）
- **暴涨的位置决定生死**：把单日大涨分成"趋势中/震荡后/超跌反弹"三类分别统计追入胜率。趋势中追入10天平均+6.9%，震荡后+11.0%（83%胜率），**超跌反弹追入平均-1.5%（40%，不能追！）**
- **暴跌后第一根大阳线一半是假反弹**：5次样本2真3假，第一根大阳线不能确认底部
- **"一直涨"是稀有事件**：连涨≥5天仅占6%，平均连涨2~3天就歇——趋势追涨必须等回调，不是连涨3天就冲
- **小阳线（+1%~+4%）次日胜率≈56%**，无信号价值（和抛硬币没区别）

### Step 4：产出可执行策略并固化
- 给出触发/进场/止损/止盈/超时/仓位的完整规则表
- 写进用户台账（个人记账台账.md 的"基金波段策略"章节）和 memory
- 完整回测数据见 `references/2026-07-31-wave-trading-dip-buy-backtest.md`

- 回测：+7%大阳线后10日追入平均+9.76%~+11.29%，盈利75~83%
- 识别：非暴跌后第一根；前1-3日已转涨或处上升趋势
- 操作：次日不破前日低点可试错，严格止损-5%
- 实案：08-04 025422 +12.59%（07-31已反弹，属确认性大阳线）→ 被原铁律一刀切踏空+15.8%

**C. 持仓者视角：+5%以上大阳线是减仓/止盈观察点，但不再是"必卖"**
- 2026-07-30 触发-10%信号 → 07-31暴涨日卖出净赚+6.5% ✅（正确流程保留）
- **冲高回落（涨幅收窄一半）才是资金跑路的硬信号**，比"大阳线"本身更可靠

**判断"大阳线日"的依据**：对应指数盘中单日涨幅≥5%（如科创芯片+8.96%）。

## 🔥 因子分解→概率矩阵判断法（"为什么跌/明天涨的概率"）

当用户问"今天为什么跌"或"明天涨的概率有多大"时，用此框架代替笼统回答：

### Step 1: 因子分解

把当天所有利空/利多因素分解出来，每个因素标注：
- 冲击天数（已price in几天了）
- 剩余冲击力（⬇️衰减中 / ➡️中期压制 / 一次性）
- 还会影响明天吗？（✅ / ⚠️ / ❌）

### Step 2: 锁定核心变量

> 决定明天走势的唯一变量：**今晚美股XXX的收盘结果**

去掉已price in的因素，保留唯一不确定的变量。

### Step 3: 概率推演矩阵

| 今晚场景 | 概率 | 明天结果 |
|:--------|:---:|:--------:|
| 🟢 反弹1~3% | **X%** | 跟涨+1~3% |
| 🟡 横盘 ±0.5% | **X%** | 平开±0.5% |
| 🔴 续跌1~3% | **X%** | 跟跌-1~2% |

概率判断依据：技术面（超卖程度/连跌天数/历史反弹概率）+ 消息面（新利空/利多）

### Step 4: 给出结论

```
胜率约X%，不算高但也不算低。关键在于你扛不扛得住到反弹兑现。
- 能扛1~2周不急 → 可以操作
- 明天不涨就焦虑 → 不要操作
```

### 周五暴涨→下周一的特殊统计（2026-07-31 回测新增）

当用户问"周五暴涨，下周一二会不会继续涨"（决定周末前卖不卖）时，用专门统计：

- **017811 周五暴涨（≥3%）后下周一上涨仅59%（10/17），周一周二连续涨仅47%（8/17）** — 周末不确定性 + 资金周一兑现倾向，比"所有暴涨后2日续涨59%"低一截
- **对比基准**：所有暴涨后2日累计为正59%、3日64%、2日平均+2.05%（61次样本）
- **结论话术**：周五暴涨后的周末持有 = 用"确定的落袋"换"可能+2%的续涨"（59%概率且要扣1.5%赎回费），不划算 → 支持周五卖出落袋
- 反面：如果暴涨发生在周一~周四，续涨概率更高，可考虑持有博弈

### 大阳线日内冲高回落识别（盘中判断卖点时机）

**大阳线当天涨幅是动态收窄的**（早盘情绪最高，午后资金获利了结），盯盘中实时估算判断卖点：

| 心理压力大 → 胡乱操作 | 心态稳 → 按纪律执行 |

## ⚠️ 硬性前置步骤（不可跳过）

**在开始任何分析前，必须先执行：**

```
terminal("date")  →  确认当前日期/时间/星期
```

- **禁止**使用会话上下文中之前查过的时间戳 — 即使几分钟前查过也不行
- **禁止**根据"我记得今天好像是周X"来推断
- **禁止**依赖模型训练数据中的日期信息
- 如果发现会话开始时间和当前时间跨天（如会话从周日延续到周一），必须重新检查
- 用户发消息的时间本身也是线索：白天发的消息（11:55）不可能还在上一个交易日

### Step 4: 给出可操作建议
遵循以下原则：
- **不恐慌**：市场回调≠基本面变坏，分清是系统性风险还是事件性回调
- **不解在高点/割在低点**：有催化事件在即（未来3-7天）的情况下，持有比卖出更优
- **定投比梭哈安全**：补仓不超过500元/次，分批操作
- **考虑实验时间线**：如果有实验结算日（如7/14），先等结算结果再调仓
- **分清板块涨跌归因**：A股半导体跌了，港股创新药可能没跟，别混为一谈
- **部分减仓（减N分之几）是折中方案**：当信号偏空但不确定时，减1/3~1/2保留大部分仓位，进可攻退可守
  - 减1/3：信号偏空但非明确利空，回收~30%现金做子弹
  - 减1/2：信号明确偏空或有重大事件（如超级IPO抽血预期）
  - 全清：只有当基本面或系统性风险确认时
  - 减仓后必须在台账标记状态为 ⏸️ 减仓N/N，方便后续补回时参考

### Step 4.5: 处理用户的直觉信号（"该跑了"模式）
用户可能说"该跑了""感觉不对""要跌了"等直觉表达。**不要无视也不要盲从**，按以下流程处理：

1. **记录用户的直觉** — 这是用户的经验/本能反应，值得严肃对待
2. **用数据验证信号清单**：
   - ⚡ 主力资金流向：该板块是否在大盘涨时净流出？（distribution pattern = 拉高出货）
   - 📢 机构观点：中金等头部券商是否提示板块风险？
   - 📅 事件日历：未来1-3天是否有已知的利空事件（超级IPO、政策发布等）？
   - 📉 板块近期涨幅：是否在7-15天内已涨超15-20%（鱼尾行情）？
3. **信号数量→减仓幅度映射（硬规则）**：
   - **4个偏空** → 全清或减2/3以上。所有信号指向同一方向，没有理由保留大部分仓位
   - **3个偏空** → 减1/2~2/3。多信号共振，不能再只减1/3意思一下
   - **2个偏空** → 减1/3~1/2。信号偏空但仍有不确定性
   - **1个偏空** → 建议不动或仅减1/3，告诉用户证据不足但尊重直觉
4. **关键原则**：减仓幅度跟着信号数量走，不是跟着"我怕卖飞"走。如果3个信号偏空还在减1/3，等于信号看见了，行动没跟上。
5. **记录决策逻辑到决策日志** — 写清楚"直觉→信号验证→减仓幅度→结果"的完整链条

#### 实盘教训：2026-07-14 芯片减仓复盘

**当时信号**：distribution（大盘涨+半导体净流出136亿） + 中金提示风险 + 超级长鑫IPO + 用户直觉"该跑了" + 芯片从07/09涨到07/10已涨15%+ → **5个偏空信号**

**实际决策**：仅减仓1/3

**结果**：07/14(周二)芯片净值3.5 → 07/16(周四)净值3.1624，随后07/17再跌-5.84%，一周从高点累计跌-22.6%。剩余2/3仓位继续承受重创。

**教训**：5个信号共振时减1/3远远不够。正确做法应该是减2/3甚至清仓。"减1/3进可攻退可守"在这种信号密度下成了"进可亏,退也亏"。详见 `references/2026-07-17-chip-crash-22pct-case-study.md`。

### Step 4.75: 已知事件的概率-盈亏影响分析
当用户针对一个**已知的具体事件**（如超级IPO申购日、政策发布、财报季）问"对我的基金影响有多少"时，不要笼统说"有影响"，按以下流程做概率分析：

1. **按基金底层资产与事件的关联度分三档**：
   - **高**（同市场+同行业）：如长鑫IPO × 科创芯片ETF
   - **中高**（同行业不同市场/产业链间接关联）：如长鑫IPO × A股半导体增强
   - **极低**（不同市场+不同行业）：如长鑫IPO × 港股创新药

2. **对每档基金构建概率-盈亏矩阵**（示例格式）：

   | 场景 | 概率 | 盈亏影响 |
   |---|---|---:|
   | 🔴 跌 -2%~-4% | 60% | -¥19~-¥29 |
   | 🟡 微跌 -1%~-2% | 25% | -¥10~-¥15 |
   | 🟢 不跌反涨 | 15% | 0~+¥10 |

3. **告知概率加权后的绝对亏损金额**。对于小规模持仓（如¥250的基金），极端场景也就是亏几块钱——这有助于用户理性看待风险，避免"觉得要亏很多"的恐慌直觉。

4. **分清短期情绪冲击 vs 中长期基本面**：超级IPO申购日是情绪抽血（资金面），上市后反而是板块催化剂（基本面）。告诉用户"申购日跌了再卖=割在最低点"。

5. **参考案例**：`references/2026-07-15-cxmt-ipo-probability-impact-analysis.md` 和 `references/2026-07-24-cxmt-ipo-probability-decision-tree.md`

### 4.75b: IPO打新参与框架（用户问"怎么从IPO里赚钱"时）

用户看到IPO消息（打新/上市）常问"对我们有什么影响，怎么赚钱"。**IPO赚钱的正解是打新（中签=白捡钱），不是买相关板块基金**——这是每次必须讲清楚的第一事实。框架：

**Step 1: 先算打新收益（用已上市同类做实证）**
- 长鑫科技(688825)实证：发行价8.66元/股，中一签500股成本4330元，上市开盘49.5元（+471%）→ **中一签赚约2.04万**（新浪数据）
- 宇树科技(688836)测算：发行底价103.9元/股，中一签成本约5.2万，若复制长鑫涨幅或赚15-20万
- 公式：`中签成本 = 发行价 × 500股`；上市首日开盘价对比发行价算收益

**Step 2: 查打新门槛（决定用户能否参与）**
- 科创板打新硬条件：前20个交易日日均资产 ≥ 50万 + 2年以上交易经验 + 沪市股票市值（场外基金/理财**不算**）
- 中签率极低：科创板A类账户年化中签率个位数百分点
- 用户一直买场外基金时，大概率没股票账户/科创板权限 → **直接告知吃不到这块肉，不纠结**

**Step 3: 给可参与路径**
| 路径 | 条件 | 收益 | 适合度 |
|:---|:---|:---|:---:|
| A. 直接打新 | 股票账户+科创板权限+沪市市值 | 中签赚10-20万 | 多数用户无资格 |
| B. 打新增强型基金 | 网下打新大户 | 蚊子肉 | 意义不大 |
| C. 情绪窗口 | 询价~申购日板块预热期 | 高波动高难度 | 有策略可做 |

**Step 4: 落地结论**
- 赚不到打新的钱（没资格）→ 能赚情绪波动的钱（回调进场+打新高潮前卖出）
- IPO对持仓的影响是短期情绪：42亿募资对A股是九牛一毛，"吸血"不是主因，"利好出尽"才是

### 4.8: IPO/重大事件概率决策树（扩展版）

当用户针对一个已知的**重大事件**（超级IPO上市、政策发布日等）问影响时，如果事件有不确定性（涨/跌都有可能），构建概率决策树：

1. **三种场景+概率**：乐观/中性/悲观，各给一个概率
2. **判断信号**：事件发生后30分钟~1小时内观察什么指标来判断是哪种场景
3. **每场景的执行计划**：跌了怎么做、涨了怎么做
4. **影响时间线**：分为冲击期/震荡期/消化期/兑现期，每个阶段对应什么操作
5. **锁利/止损条件**：具体价格或百分比位置

### Step 5: 呈现格式

#### 主动推荐格式（每日任务/盘中/复盘）
每只推荐基金必须包含完整的**交易计划表**：

| 项目 | 内容 |
|:---|---|
| 推荐基金 | XXXXXX（代码+名称） |
| 仓位等级 | **A类/B类/C类**（按铁律二定） |
| 建议投入 | ¥XXX |
| **为什么买** | 逻辑链条，不讲空话 |
| **止损线** | 亏___%必须走 |
| **止盈线** | 赚___%分批止盈 |
| **持有时间** | 至少X天，最长X天 |
| **加仓条件** | 出现什么信号加 |
| **减仓条件** | 出现什么信号减 |
| **关键观察点** | 每天要盯什么 |

#### 现有持仓分析格式
- 每只基金必须有**明确操作建议**（买/卖/减仓/清仓/持有），不得只说"持有"混日子
- 带着数据和理由，宁愿判断错了被用户骂，也不给模糊建议
- 用表格展示，每行清晰对应
- 关键日期高亮（如"**7月16日下周三**"）
- 每只基金独立分析，不笼统说"科技板块"
- 最后给一个**一句话总结**：最该做的事和最不该做的事

### Step 5.5: 处理短线/波段交易需求（"想短期赚钱，7天半个月就卖"）

当用户明确说"短期""波段""7天""半个月"等短线信号时，**切换到短线交易模式**，不再套用中长线建仓逻辑：

**第一步：判断是否适合短线**
- ⚡ **动量还在不在**？板块是否连续拉升后已涨超15-20%？如果是，这是"吃鱼尾"行情，要明确告知风险但不阻拦
- 📅 **未来7-15天有无催化剂**？政策发布、财报季、事件驱动等
- 🔄 **趋势是否完整**？均线多头排列还是已经放量滞涨？

**第二步：选定短线工具**
- C类场外联接基金（持有≥7天赎回费=0），最适合7-15天波段
- 优先选规模最大的：申赎冲击小、跟踪准

**第三步：制定止盈止损纪律 — 明确量化**

| 条件 | 动作 | 理由 |
|:---|---|:---|
| 持有满7天 | 赎回费归零，可随时走 | C类生死线 |
| **盈利≥5%** | 考虑止盈 | 短线不贪，5%在7-15天已经很好了 |
| **亏损≥3-5%** | **必须止损** | 短线纪律最重要，3%不割会拖成10%+ |
| **7天内涨超8-10%** | 立刻止盈不等 | 获利盘随时砸盘，不要恋战 |
| 到了7天+目标没到 | 评估后再决定 | 如果趋势还在可延长，否则走人 |

**第四步：主动管理型基金 vs 指数基金 — 短线选哪个**

当用户问"XX最猛的是哪只"时，可能是主动管理型基金。对比分析：

| 维度 | 指数C类（如012738） | 主动股票C类（如003231） |
|:---|---|:---|
| 弹性 | 跟指数走 | 集中度高→弹性更大，双刃剑 |
| 短线成本（≤7天/7-30天） | 1.5%/0% | 1.5%/0.5%⚠️ |
| 总费率（管理+托管+服务费） | ~0.5%/年 | ~2.3%/年（贵4倍） |
| 风险 | 分散持仓，跌了跟指数 | 集中押注，跌了更惨 |
| 依赖谁 | 市场 | 基金经理一个人 |

**主动基金什么时候比指数好：** 板块刚启动、还有空间时，主动基金靠集中持仓可以跑赢指数。**什么时候不好：** 板块已经涨了很多（如14天涨40%），主动基金弹性大就意味着回调也更狠。

**核心原则：** 用户问"最猛的"要尊重其追求弹性的意愿，但必须用"鱼尾行情"概念说明风险——已经涨了30-40%的主动基金比指数基金危险得多。如果用户坚持，控制金额在¥200以内试。

**第五步：控制仓位**
- 短线仓位不超过单次可投资金的**30-50%**
- 总金额控制在用户"亏了不心疼"的范围（如¥200-300）
- 明确告知用户：**这是短线博弈，不是投资**

**第六步：关键风险提示**
- 🐟 **"鱼尾行情"警告**：板块已涨超15-20%甚至30-40%（如003231从6/26到7/16涨40%）→ 已经是鱼尾行情，肉少刺多，追高被套概率极大。**涨幅越大，回调风险越大，这不是线性关系**。
- 🚫 **不止损是短线最大敌人** → 短线变中线变长线，越套越深
- 💰 **赎回费阶梯一定要算清楚**：C类虽然持有≥7天赎回费=0，但主动股票C类通常持有7-30天收0.5%赎回费 → 做7-15天短线前先查赎回费规则，别被"C类"两个字骗了
- 📉 大盘系统性风险 → 板块动量再好也扛不住大盘崩

**6. 响应框架**
1. 先给出能不能短线的判断（动量+催化剂+风险）
2. 推荐具体基金代码 + 理由
3. 给出具体操作时间表（今天买→X天后可卖→止损止盈线）
4. 控制预期：**短线成功赚5-10%已经很好了，不要幻想翻倍**

### 7. 饱和方向 vs 提前布局（用户说"帮我预测并推荐"时）

当用户说"根据行业信息预测并推荐基金"或表达"每次都半路上车/消息落后"时：

## 🔴 Pitfall: 重大催化剂事件必须做「精准匹配分析」，不能只停留在板块层面

**08-27 实测案例**：英伟达Q2财报（数据中心890亿+117%、Q3指引1080亿超预期），我们明确知道财报大概率好，也分析了025422（CPO）和025209（存储+模拟）的对比。但分析维度只有"位置对比"（哪个便宜），**没有做"催化匹配"（哪个被这次事件精准打中）**。结果：025209当天+4%（重仓北京君正存储芯片，完美匹配HBM高带宽内存故事），017470只+2.8%（CPO是间接受益）。

**偏差原因**：分析链在"板块受益"这一层就停了，没有继续拆到"这次事件的核心变量是什么→对应A股哪个产业链环节→观察清单里谁的重仓精准匹配这个环节"。

**修正规则：遇到重大催化剂事件（财报/政策/产业新闻），必须执行四步精准匹配：**

| 步骤 | 做什么 | 示例（英伟达财报） |
|:--|:--|:--|
| 1. 提取核心变量 | 这次事件最核心的数据点是什么？不是泛泛"利好半导体" | 数据中心890亿→HBM高带宽内存需求暴增 |
| 2. 映射产业链 | 核心变量对应A股哪些产业链环节？ | HBM需求→存储芯片（兆易创新/北京君正/佰维存储） |
| 3. 匹配基金持仓 | 观察/持仓清单里谁的重仓**精准匹配**这个环节？ | 025209重仓存储+模拟=精准匹配；025422重仓CPO=间接受益 |
| 4. 定性弹性排序 | 哪个匹配度最高=催化弹性最大=优先考虑 | 025209 > 025422 > 017470 |

**与"位置对比"的关系**：精准匹配决定"该买哪个方向"，位置对比决定"什么时候买"。两者缺一不可——只有位置对比没有催化匹配，结论是中性的"025209位置更好"（不够强，用户说"先观察"）；加上催化匹配，结论变成"025209不仅位置好，而且被这次事件精准打中，弹性最大"（强结论，可能触发行动）。

**话术模板**：
> "这次英伟达财报核心看点是HBM高带宽内存（数据中心890亿+117%），映射到A股是存储芯片链。025209重仓北京君正（存储）、佰维存储（存储模组）、德明利（存储模组），**完美匹配**；025422重仓光模块是间接受益；017470更分散。如果要吃这波催化弹性，025209是最精准的标的。"

**触发条件**：用户说"XX财报/政策出来了，对我的基金影响多大"或"XX事件哪个基金受益最大"时，自动执行四步精准匹配，不停留在板块层面。

## 🔴 Pitfall: 新基金推荐前必须做「重仓股重叠检查」，不能只看方向名称

**08-27 实测案例**：用户想买025422（浦银CPO）和025209（永赢半导体），问是否重叠。拉前十大重仓股后发现：025422的中际旭创/新易盛/天孚通信/海光信息 与 用户已有017470（科创芯片ETF）**完全重合**。买025422=加倍押注CPO，不是分散。025209则覆盖存储+模拟（兆易创新/佰维存储/圣邦股份），是真正的新方向。

### 🔴 Pitfall: 做出方向性判断前必须拉全年完整数据，不能仅凭近期片段下结论

**用户校正（2026-07-27/28）：** 电池012863分析时，用户问"8月底会不会涨"，我仅凭"消费税9月实施"这一个利空就判断"大概率不涨"。用户要求重新拉全年数据后，暴露我忽略的：

2. **历史底部形态对比的必要性**：前两次大底（2022/2024）均有"急跌→反弹+11~14%→二次探底→真反转"模式，当前才反弹+7.3%

**修正规则：做方向性判断前必须执行：**
1. 拉该基金年初以来的**全年完整净值数据**
2. 划分阶段（上升期/下跌期/当前位置）
3. 搜索历史上类似急跌后走势，**对比反弹力度和底部形态**
4. **量化每个因子的实际影响后排序**——不要放大第一眼看到的利空而忽略更大的利好
5. 输出多情景概率（A/B/C），而不是单一方向

### 🔴 Pitfall: 同类基金推荐时必须做「三阶段日级对比」，不能仅凭名称/指数匹配度推荐

**用户校正（2026-07-27）：** 推荐科创芯片(017470) vs 半导体材料设备(017811)时，我因017470名称含"科创芯片"且跟踪科创芯片指数，认为它最适合半导体方向。用户指出"跌的时候跟人家，涨得没人家厉害"。拉数据验证后，017811 在三个阶段的日级数据全面碾压：

| 阶段 | 017470 科创芯片 | 017811 半导体设备 | 
|:---|---:|---:|
| 上涨期（4/28→6/30） | +65.0% | **+110.6%** 🏆 |
| 暴跌期回撤 | -26.6% | -28.6%（仅多2%） |
| 低点反弹至7/24 | +6.4% | **+12.6%** 🏆（2倍） |
| 7/27当天 | +0.32% | **+1.74%** 🏆 |

**偏差原因：** 陷入了"名字匹配+指数匹配 = 最适合"的思维定式，没有做实际的日级涨跌对比来验证。低估了主动管理型基金（集中持仓）在上涨期的弹性优势，高估了指数基金（分散持仓）在下跌期的抗跌性。

**修正规则：在推荐任何赛道的基金前，必须执行三阶段日级对比：**

1. **拉取该赛道2-3只候选基金的最近60个交易日净值数据**（pingzhongdata API）
2. **划分三个阶段**：上涨期（冲顶）、暴跌期（从高点到最低点）、反弹期（从最低点到现在）
3. **逐阶段比较**：用表格展示每只基金各阶段的%表现，特别关注：
   - **上涨弹性**：谁涨得更多（越大越好）
   - **回撤深度差**：涨得多的基金回撤是否成比例更深？（如果A涨110%回撤28%，B涨65%回撤26% → A的涨跌比4:1，B仅2.5:1 → A更优）
   - **反弹力度比**：回撤后谁反弹更快（越大越好）
4. **输出现金比照**：用用户原话"跌的时候跟人家，涨得没人家厉害"来对照验证

**用户主动指出你推荐不够好时的处理流程（与Step 5.5中"用户学习进步信号"联动）：**

### 🔴 Pitfall: 必须为每个方向单独拉取新鲜数据，不得靠"印象"做判断

**用户明确校正过：不能只拉部分数据，其余靠记忆/常识判断。**

2. ✅ 搜索该方向近期新闻（360搜索/Bing），找到具体的催化事件

**"一日游行情"模式识别：**

### 🔴 用户说"赚不到/不知道哪里是低点高点"时的认知疏导

用户挫败时（"感觉赚不到啊，不知道哪里是低点哪里是高点"），**不要灌鸡汤也不要给新方向**，用"规则替代预测"框架：

1. **先承认他说得对**："没人知道高低点，你说得完全对"——共情是第一步
2. **把问题反转**：不需要知道高低点，因为规则已经定义了：
   - "-10%触发线 = 低点定义"（跌到线就买，不用猜）
   - "+5%止盈线 = 高点定义"（涨到线就卖，不用等）
   - "-5%止损线 = 兜底"（买错了最多亏5%）
   - "30日超时 = 资金效率"（不涨不跌就走）
3. **用已回测数据给信心**：模式A（-10%触发）6笔5盈1亏、平均+6.88%、赔率1.4:1——**83%胜率来自纪律，不是预测**
4. **指出"赚不到"的真正原因**（诚实说）：不是不知道高低点，而是**没守规则**（跌破止损没走、追涨杀跌）——规则一直都在，是执行出了问题
5. **落回当下动作**："预测交给规则，执行交给自己"——今天017811 +7%就是规则告诉你的高点，卖不卖是执行问题不是预测问题

**话术核心**：把"我不行/市场太难"的挫败感，转化为"规则在，我只需执行"的控制感。

## 陷阱提醒
- **社交媒体/大V截图必须先验证**：虚构号、段子号、营销号内容不可信
- **不要用个股逻辑套基金**：某个概念股涨停≠对应的指数基金会大涨（权重占比可能很小）
- **C类基金持有期要分两个档**：
  - **<7天**：赎回费1.5% → 超短线不能接受，至少持有>7天
  - **≥7天**：赎回费=0 → 非常适合7-15天的短线波段
  - 所以C类不是"不适合频繁进出"，而是**持有满7天后随便进出不要钱**
  - 用户说"7天半个月就卖"时，C类完美匹配，不要用"C类不适合短线"来劝阻
- **14:00前不做决策**：盘中估值与收盘净值可能有差距
- **基金转换后必须更新实验任务**：基金转换（如平安科技→半导体）后，台账更新只是第一步。如果存在引用该基金的实验结算 cron job，其 prompt 中可能硬编码了基金名称和实验描述，台账更新后必须手动重建或更新该任务。遗忘会导致结算时引用已不存在的基金。
- **基金名称 ≠ 实际持仓方向**：很多基金名字带"人工智能""数字经济"等热门标签，但实际持仓可能是半导体设备、传统IT等。用户说想买某只基金时，必须先查其前十大持仓确认实质。例如"东方人工智能主题混合C(017811)"前10大全是半导体设备公司（富创精密、华海清科、中微公司等），跟AI概念无关。如果用户已有半导体/芯片基金，买这只等于重复押注同一方向，起不到分散效果。
- **同名赛道≠同一市场/指数**：同一关键词可能有A股、港股、美股三个不同市场的指数基金。用户问"创新药"时，港股创新药(021760)和A股创新药(012738)跟踪的是完全不同市场的指数。**不要因为名字相似就说"你已经有XX了"**——先确认指数代码和市场。用户指出不同步时必须承认差异，而不是继续坚持"你有覆盖"。
- **"减仓1/3进可攻退可守"在信号共振时是假安全感**：多次验证案例（2026-07-14芯片减仓），5个偏空信号下减1/3，剩余2/3继续承受-15%+的跌幅，既没"攻"也没"守"住。减仓幅度必须跟着信号数量走：1个=1/3、2个=1/2、3个=2/3、4+=全清。详见 `references/2026-07-17-chip-crash-22pct-case-study.md`。
- 单一事件驱动逻辑不能当持有理由：长鑫申购后就反弹了、周三政策发布后就好——这是猜测不是事实。利空可能连续释放（申购+资金出逃+情绪踩踏），不能押注单一事件的拐点。如果用户已经在亏，事件逻辑要打折50%再用。
- 用户说出亏麻了时立即切换保护模式：这说明你之前所有建议都偏保守了。不要解释我建议减仓了呀——如果结果是大亏，你减的幅度就不够。立即认错，给出更激进的保护方案（减1/2~全清），不要在这个节骨眼上说等反弹。
- 日期混用陷阱：会话跨越多个自然日时（例如从周一21:41讨论到周二11:55），之前查的日期数据全部失效。每次用户发新消息涉及时间判断，必须先 date 重新确认。用户明确批评过为什么又犯这种错误。

## 饱和度检查（用户想加仓/买新基金时）
用户说"加仓X"或"买Y"时，先做持仓饱和度分析，再给建议：

1. **⚠️ 先确认市场/指数是否一致** — 同名不同市不算"重复押注"（如A股创新药与港股创新药是不同市场的独立配置），但也要考虑资金分散程度
2. **查持仓占比**：计算当前各赛道占比（如芯片+半导体占88% vs 创新药占12%）
3. **查新基金实质**：拉前10大持仓，看跟已有基金是否重叠（统一方向还是不同赛道）
4. **给出结论**：
   - 同方向重复押注 → ❌ 不建议（先分散再考虑加）
   - 不同赛道 → ✅ 可以考虑（但也要结合实验时间线和市场位置）
   - 同名不同市 → 说明差异，让用户选：继续加已有方向还是开新市场
